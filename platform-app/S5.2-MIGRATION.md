# Phase 5 (S5.1–S5.7) — frontend migration record

Status of the platform app after Phase 5. Section 2 is the first draft of this file, kept as history
and labelled with what happened to each item.

## 1. Final state

### S5.1 Tokens + DESIGN.md — Implemented
- `tailwind.config.js` extended (not replaced): `-fg` text colours for the semantic and accent
  palettes (WCAG AA), `font-sans`/`font-mono` tokens (fonts via `next/font`, no `<link>`), `text-2xs`,
  `w-sidebar`, `max-h-modal`, z-index scale. `DESIGN.md` documents every token and rule.
- `globals.css` rules are inside `@layer base/components`: the old unlayered `* { padding: 0 }` and
  `a { color }` silently overrode Tailwind v4 utilities. The `.status-badge` classes were removed
  (replaced by `<StatusBadge>`).
- Validation: `grep -rE "(bg|text|border)-(emerald|red|gray|blue|amber)-[0-9]{3}" src/` → no hits;
  ESLint now fails on any raw palette class. Arbitrary values (`[12px]`-style) in `src/`: 0.

### S5.2 UI primitives — Implemented
- `src/components/ui/`: Button, Input, Textarea, Select, Switch, Card, Badge/StatusBadge, Alert,
  Spinner/LoadingState/EmptyState, PageHeader, Meter, InfoRow, Modal, Table (+THead/TBody/Tr/Th/Td),
  Tabs/TabPanel, FilterChips, Pagination, CopyButton. D5 was not "shadcn/Radix": the primitives are
  local components on the existing tokens; Modal uses the native `<dialog>` instead of Radix Dialog.
- Every page uses them: no raw `<table>` outside `ui/Table.tsx`, no hand-rolled modal, one inline
  `style` (the data-driven width inside `Meter`).

### S5.3 Accessibility baseline — Implemented in code; NOT verified with axe or a keyboard walkthrough
- Labels on every control (required `label` prop), `scope` on every `<th>`, captions on every table,
  `aria-label` on icon-only buttons, `aria-hidden` on decorative SVGs, global `:focus-visible` ring,
  skip link, `aria-current` in navigation, modal focus trap + Escape + focus return, text equivalents
  for every colour-coded value (risk level words, `role="meter"` with `aria-valuetext`).
- Static check: `jsx-a11y` recommended rules run in `npm run lint` (0 findings).
- Open: the roadmap's axe scan and keyboard-only walkthrough need the app running against a backend;
  they were not run.

### S5.4 Data layer — Implemented
- Session (ruling D11): the backend sets the httpOnly `finshield_session` cookie on login/register and
  clears it on `POST /api/auth/logout`. The browser stores no token; all calls are same-origin through
  the `/api` rewrite; non-GET requests send `X-Requested-With` (backend CSRF check).
- `lib/api.ts`: one transport; a 401 mid-session clears the cookie and goes to
  `/login?expired=1&redirect=<path>`; a 401 from login stays a login error ("Invalid email or
  password"); FastAPI 422 details are rendered readably; the dead `body.detail || body.detail?.message`
  branch is gone.
- SWR for reads (`swr` dependency; global config in `components/Providers.tsx`). Transactions paginate
  server-side with `limit/offset` + `X-Total-Count`; audit and webhook logs paginate server-side with
  the `total` in their responses. Cases and filings paginate client-side (their endpoints have no
  limit/offset).

### S5.5 Route protection + role-gated navigation — Implemented
- `src/proxy.ts` (Next 16 name for middleware): page requests without the session cookie redirect to
  `/login?redirect=<path>`; `/` goes to `/dashboard` or `/login`. After login the app returns to the
  `redirect` target if it is a same-site relative path (`lib/routes.ts` `safeRedirect`).
- Roles come from `GET /api/auth/me` (`user.role`). `lib/permissions.ts` is a line-for-line mirror of
  `backend/app/permissions.py` MATRIX; nav items, page access (403 state in the layout) and action
  buttons are derived from it. The UI only hides; the API enforces.

### S5.6 Built-but-unused backend + real API docs — Implemented
- New screens: `/users` (admin), `/webhooks` (subscriptions + one-time secret, delivery log, retry),
  `/audit` (filters, verify, signed export download, public key), `/privacy` (log / execute / outcome),
  `/operations` (circuit breakers + reset, list freshness, flags, model versions + promote, runtime
  settings). Also: rule stats + simulator, case notes, SLA sweep, case aggregation, drafting a filing
  from a case, behavioral baseline and decision reasons in the transaction detail.
- `/docs` renders `/api/openapi.json` at runtime; there is no hand-maintained endpoint list.

### S5.7 Live updates — claim dropped, honest polling
- The dashboard polls stats and recent transactions every 15 s while the tab is visible and shows
  "Last updated hh:mm:ss"; notifications poll every 30 s. No "real-time" copy remains in `src/`.
  `useSSE.ts` (targeting a non-existent endpoint) was deleted.

### Tooling / container
- `npm run lint` = `eslint . --max-warnings=0 && tsc --noEmit` with the native flat config from
  `eslint-config-next` 16 (`eslint.config.mjs`); the broken `FlatCompat` config and `.eslintrc.json`
  were removed.
- `next.config.js`: CSP without `'unsafe-eval'` in production, `connect-src 'self'`, no external font
  or image origins; headers apply to pages, not to the proxied `/api/*`.
- `Dockerfile`: multi-stage, `npm ci` with dev dependencies for the build, `API_URL` set at build time
  (rewrites are baked in), non-root standalone runtime, health check on `/login`.

## 2. First draft (Qoder snapshot) — history

> Original text, with the outcome of each item.

- **UI Components Created** (Button, Input, Select, Card, Badge, Modal, Alert, Spinner, Table) —
  *rewritten*: labels made mandatory, ARIA added, Modal moved to native `<dialog>`, Table given
  required captions and `scope`, text colours moved to `-fg` tokens.
- **"Modal — backdrop, escape key"** — *kept and extended* (focus return, Tab wrap, labelled title).
- **"Pages migrated: login/page.tsx"** — *superseded*: every page is migrated (section 1).
- **"All components use design tokens (no hardcoded palette colors)"** — *true then, now enforced* by
  ESLint.
- **`src/middleware.ts`** — *replaced* by `src/proxy.ts`: it required a `finshield_token` cookie that
  nothing set and checked a non-existent `user_role` cookie and `super_admin` role.
- **`AuthGuard` role map** (settings/api-keys admin-only, rules analyst+) — *removed*: it compared
  against `user.plan` and contradicted the backend. Role gating now mirrors `permissions.py`.
- **`useApi.ts` (SWR hooks), `useSSE.ts`, `/403` page, `scripts/migrate-design-tokens.js`** —
  *deleted*: unused, or (SSE) aimed at an endpoint the backend does not have. SWR is used directly.
- **Settings saved-card UI** — *deleted*: card columns were removed from the backend (S3.5); checkout is
  Stripe Checkout or the backend's labelled simulated mode.
- **Validation: "`npx tsc --noEmit` passes with 0 errors"** — still true; now part of `npm run lint`.
