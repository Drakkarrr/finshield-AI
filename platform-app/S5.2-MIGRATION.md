## Migration Pattern

When migrating other pages:

```tsx
// Before
<input className="w-full bg-bg border border-border rounded-xl px-4 py-2.5 text-sm text-ink" />
<button className="bg-accent hover:bg-accent-dark text-white font-semibold px-4 py-2.5 rounded-xl" />

// After
import { Input, Button } from '@/components/ui';

<Input label="Email" type="email" />
<Button variant="primary">Submit</Button>
```
