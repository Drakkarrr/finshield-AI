Schema is managed by Alembic (`alembic upgrade head` runs in the container entrypoint via `entrypoint.sh`); test suite bootstraps an in-memory SQLite DB through `database.create_test_schema()` unless `TEST_DATABASE_URL` points at Postgres so CI can validate migrations against the real dialect. The app requires `DATABASE_URL=postgresql://...` in production and optionally `RAG_DATABASE_URL=postgresql://...` plus `RAG_USE_SENTENCE_TRANSFORMERS=true` to enable vector search.
