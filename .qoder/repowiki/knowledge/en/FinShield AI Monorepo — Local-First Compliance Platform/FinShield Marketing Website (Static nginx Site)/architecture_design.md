Pure static site deployed as an `nginx:alpine` container — `Dockerfile` removes the default config, copies `nginx.conf` into `/etc/nginx/conf.d/default.conf`, and serves everything from `/usr/share/nginx/html`. `nginx.conf` defines gzip compression, security headers (`X-Frame-Options`, `X-Content-Type-Options`, `X-XSS-Protection`), immutable 30-day caching for assets under `location ~* \.(css|js|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot)$`, SPA fallback via `try_files $uri $uri/ /index.html`, and a `/health` endpoint returning 200. The site is split into three content areas: the main marketing page (`index.html`) with embedded sections (hero, trust bar, services, portfolio, stats, pipeline, industries, security, awards, testimonials, CTA form, FAQ, footer); informational sub-pages under `pages/` (`about.html`, `contact.html`, `login.html`, `portfolio.html`, `pricing.html`, `resources.html`, `signup.html`); and an admin shell under `pages/admin/dashboard.html` plus a `platform/` folder that links out to the Next.js app at `http://localhost:3000/login|signup`. Styling lives in `css/main.css` (shared across all pages) plus `css/admin.css` and `css/platform.css` scoped to those shells; interactivity is centralized in `js/main.js` (mobile menu, FAQ accordion, IntersectionObserver fade-in/reveal animations, smooth anchor scrolling, pipeline diagram animation, magnetic button hover, glassmorphism tilt). There is no build step — files are copied verbatim into the image.
