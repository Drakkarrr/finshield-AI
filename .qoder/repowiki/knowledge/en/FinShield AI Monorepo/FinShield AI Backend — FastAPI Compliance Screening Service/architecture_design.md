Layered FastAPI application rooted at `app/main.py`, which wires CORS, slowapi rate limiting, global exception handlers, request-logging middleware, and registers routers from `app/api/` (auth, transactions, cases, filings, billing, stats, search, notifications, rules, behavioral, breakers, webhooks, privacy, rag, settings, health) in route-matching order.

- Domain layer: `app/compliance_engine.py` implements the 7-stage pipeline (`screen`) — idempotency → validation → rule engine → behavioral analysis → ML classification → risk scoring → decision — driven by `ScreeningConfig` from `app/config_service.py`. Hard rules (sanctions, PEP, threshold, geography) are defined inline with per-user overrides via `rule_configs`; fallback hardcoded lists (`SANCTIONED_ENTITIES`, `PEP_ENTITIES`, `HIGH_RISK_COUNTRIES`) are used when no DB session is supplied.
- Persistence: `app/database.py` exposes a single SQLAlchemy engine/session factory; it forces PostgreSQL outside `APP_ENV=test` (SQLite only for tests) and provides `create_test_schema()` that either calls `Base.metadata.create_all` (SQLite) or runs Alembic migrations programmatically.
- ORM models: `app/db_models.py` declares all tables on one shared `Base` consumed by Alembic (`migrations/versions/0001_baseline_schema.py`, `0002_runtime_settings.py`). Includes core entities (User, ApiKey, Transaction, Case, Filing, AuditLog, Notification, RuleConfig, CircuitBreaker, WebhookEvent, AccountBaseline, Setting, FeatureFlag) plus pgvector-backed RAG corpora (ComplianceDocument, SanctionsEntry, PrecedentDecision).
- Optional RAG: `app/rag_service.py` is imported lazily in `main.py`; when `RAG_DATABASE_URL` starts with `postgresql` and optional deps exist, a `RAGRetrievalService` is attached to `app.state.rag_service`. Embeddings default to deterministic hashing into 384-dim vectors (numpy-only); `sentence-transformers` (`all-MiniLM-L6-v2`) is used if `RAG_USE_SENTENCE_TRANSFORMERS=true`.
- Behavioral scoring delegates to `app/domain/behavioral/scoring.py` with a heuristic fallback when no DB/user_id is supplied.
- Auth: `app/auth.py` provides JWT (HS256) bearer tokens and `fsk_`-prefixed API key auth, bcrypt password hashing, and an RBAC permission matrix (`user`/`analyst`/`admin`/`super_admin`) exposed via `require_role` / `require_permission` decorators.
- Dependency direction: api modules → compliance_engine / config_service / database → db_models; rag_service depends on db_models but not on the API layer.
